# Customer Behaviour Analysis Dashboard

## Overview

This project is an end-to-end Data Analytics project focused on analyzing customer shopping behavior and generating business insights using Python, SQL, PostgreSQL, and Power BI. The project covers the complete analytics workflow from data cleaning and exploratory analysis to dashboard development and business reporting.

## Dataset

The dataset contains customer shopping behavior information such as:

* Customer demographics
* Product categories
* Purchase amounts
* Review ratings
* Subscription status
* Shipping methods
* Discounts and purchase frequency

## Tools & Technologies

* Python
* Pandas
* NumPy
* PostgreSQL
* SQL
* Power BI
* Jupyter Notebook
* Gamma (for presentation)

## Project Steps

1. Loaded and explored the dataset using Python
2. Performed data cleaning and preprocessing
3. Conducted Exploratory Data Analysis (EDA)
4. Imported cleaned data into PostgreSQL
5. Wrote SQL queries to answer business questions
6. Built an interactive Power BI dashboard
7. Created a business report and presentation

## Dashboard Features

* Revenue analysis by category
* Customer segmentation
* Subscription behavior analysis
* Age-group sales insights
* Shipping type analysis
* KPI cards and interactive filters

## Key Results

* Identified top-performing product categories
* Analyzed customer purchase behavior
* Compared subscriber vs non-subscriber spending
* Discovered revenue contribution by age groups
* Generated business insights through visualization

## How to Run

1. Open the Jupyter Notebook file
2. Run Python scripts for data cleaning and analysis
3. Import the cleaned dataset into PostgreSQL
4. Execute SQL queries
5. Open the Power BI `.pbix` file to view the dashboard
